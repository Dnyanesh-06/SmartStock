# SmartStock – Inventory Management System

## Project Overview

SmartStock is a web-based Inventory Management System developed as a full-stack application.

The system allows users to add, view, search, update, and delete products while maintaining inventory quantity and price information in an SQLite database.

The application follows a client-server architecture with a JavaScript frontend, Flask backend, REST APIs, and SQLite database.
